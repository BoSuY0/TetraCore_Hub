# Виправлення авторизації TetraCore Hub

## Проблема
Сайт хабу повертає помилки 401 та не може авторизуватися через відсутність необхідних секретів.

## Розв'язання

### Швидке виправлення
```bash
cd tetra-core-hub
./fix_heroku_auth.sh
```

### Ручне виправлення

1. **Переконайтесь, що у вас встановлено Heroku CLI:**
   ```bash
   heroku login
   ```

2. **Запустіть скрипт налаштування:**
   ```bash
   python3 setup_heroku_secrets.py
   ```

3. **Перезапустіть додаток:**
   ```bash
   heroku restart --app НАЗВА_ДОДАТКУ
   ```

## Що виправляється

- ✅ **JWT_SECRET_KEY** - ключ для JWT токенів
- ✅ **JWT_REFRESH_SECRET** - ключ для refresh токенів  
- ✅ **ADMIN_USERNAME** - ім'я адміністратора
- ✅ **ADMIN_PASSWORD** - пароль адміністратора (відповідає вимогам безпеки)
- ✅ **ENCRYPTION_KEY** - ключ для шифрування
- ✅ **RedisManager** - виправлена ініціалізація
- ✅ **WebSocket авторизація** - додана передача токенів

## Після виправлення

1. Перейдіть на https://hub.tetra-core.website
2. Увійдіть використовуючи дані з файлу `admin_credentials.txt`
3. Перевірте, що всі функції працюють

## Додаткове налагодження

Якщо проблеми залишаються:

1. **Перевірте змінні середовища:**
   ```bash
   heroku config --app НАЗВА_ДОДАТКУ
   ```

2. **Перегляньте логи:**
   ```bash
   heroku logs --tail --app НАЗВА_ДОДАТКУ
   ```

3. **Перезапустіть додаток:**
   ```bash
   heroku restart --app НАЗВА_ДОДАТКУ
   ```

## Безпека

⚠️ **Важливо:** Дані для входу зберігаються в `admin_credentials.txt`. Не додавайте цей файл до git репозиторію!
